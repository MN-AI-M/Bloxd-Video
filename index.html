操作ヘルプ

基本の流れ: 右ドラッグで見回しながら WASD で良いアングルへ → F でカメラを置く → 再生ヘッドを進めて別の場所へ飛ぶ → K でキーを記録 (これで動くショットになります) → Space で再生して確認。
構図を直したい時は、カメラを選んで V(カメラ視点)→ 動かして K。

視点の操作

右ドラッグ(Alt+左ドラッグ)見回す
WASD移動(右ドラッグ中はさらに Space/Shift で上下)
Q / E下降 / 上昇
右ドラッグ中にホイール移動速度を変える
ホイール前後に移動
中ボタンドラッグ平行移動
✈ 飛行モードマウスを捕まえて飛ぶ(トラックパッド向け、Escで終了)

カメラ

F今の構図で、再生ヘッドの位置にカメラを置く
K今の構図を、再生ヘッドの時刻のキーとして記録
G最後のポイントの2秒後に、今の構図を継ぎ足す
V選択中のカメラの目線に入る/戻る
箱をクリックそのカメラ・ポイントを選ぶ
矢印 / リングをドラッグ選んだポイントの位置 / 向きを直す

タイムライン

Space再生 / 一時停止
← →1コマ移動(Shiftで1秒)
Home End先頭 / 最後へ
ルーラーをドラッグ再生ヘッドを動かす(Altで吸着しない)
Ctrl/Cmd+ホイール拡大・縮小(トラックパッドはピンチ)
ブロックを上下にドラッグカメラの重なり順(上ほど手前)
◆ をドラッグそのポイントの時刻を変える

編集

Ctrl/Cmd+Z取り消し
Ctrl/Cmd+Shift+Zやり直し
B選択中のブロックを再生ヘッドで分割
Ctrl/Cmd+D複製
Delete削除(◆を選んでいればそのポイントだけ)
ダブルクリック編集パネルを開く
Escカメラ視点・パネルを閉じる / 選択を外す
